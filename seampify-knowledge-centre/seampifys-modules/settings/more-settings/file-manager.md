# File Manager

Here, you can upload files in your Seampify account and manage them efficiently.



To access File Manager, go to **Settings** then click on the **File Manager** tab.

<figure><img src="../../../.gitbook/assets/image (638).png" alt=""><figcaption></figcaption></figure>



## Upload a file to File Manager

{% stepper %}
{% step %}
Click on the **+ Upload File** button

<figure><img src="../../../.gitbook/assets/image (639).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
In the Upload File modal, click **Choose File** to browse the file on your system and select it. Then, if you want to make the file accessible to all users in your Seampify account, click **Add to common files**.&#x20;

<figure><img src="../../../.gitbook/assets/image (640).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Once done, click **Upload**. The uploaded file will appear like the below. Use _Search Files_ to locate a file quickly. To delete a file, click on the Delete Icon button. And to download it, click on the Download Icon button.

<figure><img src="../../../.gitbook/assets/image (641).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

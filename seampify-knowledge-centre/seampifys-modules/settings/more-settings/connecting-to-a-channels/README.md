# Connecting to a Channels

Seampify lets you manage your chat commerce through Channels.



The Channels available at Seampify are a bridge that lets you connect different chat platforms to the Seampify Chat. Using it, you can easily manage messages that you send and receive across multiple platforms.



## Create a Channel

To create a channel, simply choose the channel you wish to connect and click _Configure_. It will open a popup where you need to enter the details to complete the process.

<figure><img src="../../../../.gitbook/assets/image (521).png" alt=""><figcaption><p>Channels in Seampify</p></figcaption></figure>

If you have already created a channel before, the Channels window then shows a channel list allowing you to apply changes to existing channels or accessing its settings easily.

<figure><img src="../../../../.gitbook/assets/image (522).png" alt=""><figcaption></figcaption></figure>

To add another channel(s) from here, click on the **+ Create Channel** button and it will open a popup asking which Channel connection you want to create.

{% hint style="warning" %}
To learn how to get the required details, you can explore individual guides of each channel.
{% endhint %}

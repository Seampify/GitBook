# Coupon Code Template

Looking for a simple way to share promo codes with your customers via WhatsApp? Now you can do it more efficiently with the **Coupon Code Templates Message** feature.

Coupon code templates are marketing templates that display a single copy code button. When tapped, the code is copied to the customer's clipboard.

<figure><img src="../../../../../.gitbook/assets/image (856).png" alt=""><figcaption></figcaption></figure>

## Limitations <a href="#limitations" id="limitations"></a>

* Coupon code templates are currently not supported by the WhatsApp web client.
* Codes are limited to 15 characters.
* Button text cannot be customized.
* Templates are limited to one copy code button.



## Creating a Coupon Code Template

Here is a step by step guide on how to create a template message to send offer coupons.

{% hint style="info" %}
**Note: This is only available on the Marketing-Standard Template.**
{% endhint %}

### Accessing Message Template

* **Navigate to**: Settings → Channels.
* **Manage Templates**: Click the "Manage Templates" tab under the Channel section.

<figure><img src="../../../../../.gitbook/assets/image (854).png" alt=""><figcaption></figcaption></figure>

### **Creating a Carousel Message Template**

* **Click**: "+ Create WhatsApp Template" button.

<figure><img src="../../../../../.gitbook/assets/image (765).png" alt=""><figcaption></figcaption></figure>

* A popup will appear for creating the template.

<figure><img src="../../../../../.gitbook/assets/image (766).png" alt=""><figcaption></figcaption></figure>

**Template Details**:

* **Name**: Enter a unique template name (duplicate names are not allowed).
* **Category**: Select Marketing.
* **Language**: Choose the language matching the body text content.

### Setting Up Template

1. Select **Standard** as the marketing template.
2. **Body**: Add the text (Mandatory)
3.  **Add Button**:

    **Type**: Choose Copy Code, and type in the sample code.
4.  **Submit for Approval:**

    Once everything is set, submit the template for approval.

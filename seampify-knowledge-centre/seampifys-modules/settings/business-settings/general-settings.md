# General Settings

Using the **General Settings** option under the Business Settings, you can manage the following details:

* [General Informations](general-settings.md#general-informations)
* [Live Translation Settings](general-settings.md#live-translation-settings)
* [Agent Offline Statuses](general-settings.md#agent-offline-statuses)
* [Blacklisting Settings](general-settings.md#blacklisting-settings)
* [Report Crons](general-settings.md#report-crons)



## General Informations

Here, you can manage the following details:

* Business Name
* Default Country Code
* Default Timezone
* Date Format
* API Key

### Edit General Informations

To add the information or make changes to it, click the Edit icon.

<figure><img src="../../../.gitbook/assets/image (526).png" alt="" width="375"><figcaption></figcaption></figure>

Then, you get the fields to add the information or make changes. Simply input the Business Name first, then the Billing Address. Choose Default Country Code, Time Zone and Date Format. Once you're done editing or adding the info, click **Update** to save changes.

<figure><img src="../../../.gitbook/assets/image (525).png" alt="" width="375"><figcaption></figcaption></figure>

If you're required to access the API Key of your Seampify business account, you can obtain that by clicking the **Copy** button under API Key. And if, in any scenario, you need to change the API, then you can do that by clicking the **Regenerate Key** button.

<figure><img src="../../../.gitbook/assets/image (527).png" alt="" width="563"><figcaption></figcaption></figure>

### Reset All Data

If you're required to delete all of your data from Seampify, for example, contacts, chat, campaigns and more, then you can do that by clicking the **Clean** icon.

<figure><img src="../../../.gitbook/assets/image (528).png" alt="" width="563"><figcaption></figcaption></figure>

It will open the Clear All Data confirmation popup. To finalise cleaning, click **Confirm**. And all of your data will be removed safely.

<figure><img src="../../../.gitbook/assets/image (529).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="danger" %}
This step will erase all datas in your Seampify account.
{% endhint %}



## Live Translation Settings

Look for an option to enable live or real-time translation. This setting ensures that transactions occur as conversations happen in real-time.

<figure><img src="../../../.gitbook/assets/image (530).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="warning" %}
To use this feature, you will need to generate a Google Translate Key.
{% endhint %}



## Agent Offline Statuses

Define a list of offline status options for your user. If this is a mandatory step for a user to fill up when they set themselves as Offline, turn on for the Is other reason required? option.

## Blacklisting Settings

Define any keyword here to automatically mark a contact as blacklisted. Once configured, any incoming message that matches the keyword will result in the contact being marked as blacklisted.

<figure><img src="../../../.gitbook/assets/image (534).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="warning" %}
Once a contact is blacklisted, automations will not run, and the contact will not receive any business-initiated messages.
{% endhint %}



## Report Crons

The **Report Crons** function allows you to send reports of failed cases when a REST API call is used within an automation. These reports can be shared to recipient email(s) for monitoring and resolution.

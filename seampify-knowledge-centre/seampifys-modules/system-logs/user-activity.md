# User Activity

This section records activity details for each of your team members.&#x20;



To access User Activity, go to **System Logs** then click on the **User Activity** tab.

<figure><img src="../../.gitbook/assets/image (657).png" alt=""><figcaption></figcaption></figure>



## Viewing the User Activity informations

To view conversation details, you must first apply filters. You can filter by:

* **Date Range** - Select a time frame for the message history: Today, Yesterday, Last 7 Days, Last 30 Days and Custom.

{% hint style="info" %}
User activity may take some time to capture, so the "Today" date range might not show any activity yet.
{% endhint %}

* **Team Member** - Choose the specific team member(s) whose activity you wish to view.

<figure><img src="../../.gitbook/assets/image (691).png" alt=""><figcaption></figcaption></figure>



## Exporting the User Activity

Click on the <img src="../../.gitbook/assets/image (648).png" alt="" data-size="original"> button to download the filtered information as a CSV file into your system.

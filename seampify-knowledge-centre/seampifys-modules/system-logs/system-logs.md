# System Logs

This section records the REST API logs in your Seampify account, providing a detailed history of API activities.



To access System Logs, go to **System Logs** then click on the **System Logs** tab.

<figure><img src="../../.gitbook/assets/image (690).png" alt=""><figcaption></figcaption></figure>



## System Logs Filter Functions:

* **Date Range** - Select a time frame for the message history: Today, Yesterday, Last 7 Days, Last 30 Days and Custom.
* **Logs type** - Select the type of logs to view: **All**, **Dynamic Webhook**, **Marketplace Apps**, or **Rest API**.
* **Status Code** - Filter by available status codes to narrow down the results.
* **Search Bar** - Filter the logs by entering a contact's name or phone number, displaying all system logs associated with that contact.

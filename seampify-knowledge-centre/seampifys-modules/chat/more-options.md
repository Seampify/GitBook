# More Options

More options of the chat module lets you perform advanced actions to the chat. For instance, you can change Conversation Status; Message Read Status; assign Bot and more.

## Conversation Status <a href="#conversation-status" id="conversation-status"></a>

{% hint style="info" %}
Only for Facebook and WhatsApp Official API Channels.
{% endhint %}

Through Conversation Status, you can set the chat to Open, Waiting For Customer, and Closed.

{% stepper %}
{% step %}
Click on the Conversation Status drop down button and select the status.

<img src="../../.gitbook/assets/image (319).png" alt="" data-size="original">
{% endstep %}

{% step %}
In the Conversation Status Popup, you may add a comment and sent a message to customer at the same time. Leave this blank if you do not wish to sent anything.

<img src="../../.gitbook/assets/image (318).png" alt="" data-size="original">
{% endstep %}

{% step %}
Click **Save** to apply changes.

<img src="../../.gitbook/assets/image (320).png" alt="" data-size="original">
{% endstep %}
{% endstepper %}

## Read Status <a href="#read-status" id="read-status"></a>

Go to the drop down button beside the Conversation Status, then select either,

* **Mark as Unread**.
* Or **Mark as Read**.

## Other Functions <a href="#read-status" id="read-status"></a>

* **Mark as Blacklist** - You may mark contact blacklist here. Once blacklisted, the system will not send any sort of [business-initiated messages (Template Message)](../../useful-guides/conversation-through-whatsapp-cloud-api-1/understanding-whatsapp-message-template/). You are still able to receive incoming messages and reply manually during the [24 Hour Customer Service Window](../../useful-guides/conversation-through-whatsapp-cloud-api-1/understanding-24-hour-customer-service-window.md).
* Assign Contact
* Push Chat to Queue
* Unassign
* Pin / UnPin Contact
* [Add to Drip Campaign](../drip-campaign/adding-contacts-into-drip-campaign.md#assigning-contacts-to-a-drip-campaign-using-chat)
* Create Follow Up
* Delete Contact

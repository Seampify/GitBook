# Contact Info

This section contains the information and profile of your contact.&#x20;

<figure><img src="../../.gitbook/assets/image (313).png" alt="" width="240"><figcaption></figcaption></figure>

* **Contact Name** – This information will be automatically captured if it's a new contact. Once captured or edited, the name will not change unless you manually edit it.
* **Phone Number** - This is the contact's WhatsApp number.
* **Email** - If you have entered an email address, it will be displayed here.

{% hint style="info" %}
Some channel might not have the Phone Number section.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (314).png" alt="" width="241"><figcaption></figcaption></figure>

* **Assigned Agent** - You may manually assign to a user from the drop down menu here.
* **Assigned Department** - You may manually assign to a department from the drop down menu here. If you wish to assign to yourself, select **Assign to Me**.
* **Additional Chat Members** - In some cases where you wish to invite your team member to view the contact's conversation, you may click + to add them.

<figure><img src="../../.gitbook/assets/image (315).png" alt="" width="240"><figcaption></figcaption></figure>

* **Contact Attributes** - If any of the [Contact Fields](../contacts/filter-options/contact-fields.md#create-a-contact-field) that has data and you have enabled to Show On Contact Grid, it will display here.

<figure><img src="../../.gitbook/assets/image (316).png" alt="" width="241"><figcaption></figcaption></figure>

* **Full Name** - You may edit the contact Full Name here.
* **Tags** - You may add any existing or a new Tag here.&#x20;
* **Remarks** - You may add any remarks about this contact here for internal references.

## Steps to add an existing Tag

{% stepper %}
{% step %}
Click on the Tags field bar to display a list of created Tags.
{% endstep %}

{% step %}
Select the Tag you wish to add.
{% endstep %}

{% step %}
Click Save once you're done.
{% endstep %}
{% endstepper %}

## Steps to add a new Tag

{% stepper %}
{% step %}
Click on the Tags field bar, type the desired tag, and hit Enter to create it.
{% endstep %}

{% step %}
Click Save once you're done.
{% endstep %}

{% step %}
Refresh the page to have the newly added Tag appear in the drop-down list for future usage.
{% endstep %}
{% endstepper %}

## Editing A Contact Informations

To edit a contact using chat, click <img src="../../.gitbook/assets/image (312).png" alt="" data-size="line"> in the contact info.

<figure><img src="../../.gitbook/assets/image (322).png" alt="" width="375"><figcaption></figcaption></figure>

The Edit Contact popup will appear. Here, you can edit the contact details such as Phone Number, Tags, Full Name, Email, Time Zone, Custom Fields and more.

Once edit the contact, click **Save**.

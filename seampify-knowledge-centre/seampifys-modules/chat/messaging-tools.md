### Quick Reply <a href="#quick-reply" id="quick-reply"></a>

There are 3 ways to send a quick reply, which you've created using the Quick Reply tab in Settings:

* Click the plus button icon![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FJMY2HDDt6VkJxUmqEb5C%252FPlus%2520Icon%2520in%2520the%2520RUM%2520Work%2520Chat.png%3Falt%3Dmedia%26token%3D2f41a934-4d09-432c-b72c-ae74e0de09b4\&width=40\&dpr=4\&quality=100\&sign=b959a10e\&sv=2), then select **Quick Reply**.
* Click the / button.
* Type backslash / on the messaging area.&#x20;

A popup will appear with all the quick replies created in your Seampify account. Select the one you want to send, and then click the send button![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FHVWdk5Ki6PZL6fH1iV4t%252FSend%2520Button.png%3Falt%3Dmedia%26token%3D97b379a9-4dfe-4c5f-ab28-5ea724b5f02c\&width=35\&dpr=4\&quality=100\&sign=2c5f6f2f\&sv=2)

<figure><img src="../../.gitbook/assets/reply.gif" alt="" width="563"><figcaption></figcaption></figure>



### **Send Contact** <a href="#send-template-message" id="send-template-message"></a>

If you wish to send a contact, click the plus button icon![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FJMY2HDDt6VkJxUmqEb5C%252FPlus%2520Icon%2520in%2520the%2520RUM%2520Work%2520Chat.png%3Falt%3Dmedia%26token%3D2f41a934-4d09-432c-b72c-ae74e0de09b4\&width=40\&dpr=4\&quality=100\&sign=b959a10e\&sv=2), then select **Send Contact**.

<figure><img src="../../.gitbook/assets/image (679).png" alt="" width="485"><figcaption></figcaption></figure>

This will open a Send Contact popup, fill up the information and click **Share.**&#x20;

<figure><img src="../../.gitbook/assets/image (680).png" alt="" width="563"><figcaption></figcaption></figure>

### **Send Template Message** <a href="#send-template-message" id="send-template-message"></a>

If you've [created template message](../settings/more-settings/channels/manage-templates/#create-a-template-messages) and want to send it, click the plus button icon![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FJMY2HDDt6VkJxUmqEb5C%252FPlus%2520Icon%2520in%2520the%2520RUM%2520Work%2520Chat.png%3Falt%3Dmedia%26token%3D2f41a934-4d09-432c-b72c-ae74e0de09b4\&width=40\&dpr=4\&quality=100\&sign=b959a10e\&sv=2), then select **Send Template Message**.

<figure><img src="../../.gitbook/assets/image (677).png" alt="" width="489"><figcaption></figcaption></figure>

Then, from the Select Template popup, select the template you want to send. And once selected, click **Send**.



### Send Buttons/Options/Product Messages <a href="#send-buttons-options-product-messages" id="send-buttons-options-product-messages"></a>

If you've [created interactive messages](../settings/more-settings/channels/interactive-messages.md#create-an-interactive-message) before using the supported channels, click the plus button icon![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FJMY2HDDt6VkJxUmqEb5C%252FPlus%2520Icon%2520in%2520the%2520RUM%2520Work%2520Chat.png%3Falt%3Dmedia%26token%3D2f41a934-4d09-432c-b72c-ae74e0de09b4\&width=40\&dpr=4\&quality=100\&sign=b959a10e\&sv=2), then select **Send Buttons/Options/Product Messages**.

<figure><img src="../../.gitbook/assets/image (678).png" alt="" width="485"><figcaption></figcaption></figure>

Then from the Send Interactive Message popup, select your message and click **Send**.



### Attach File <a href="#attach-file" id="attach-file"></a>

Using Seampify Chat, you can also send files to your customers.&#x20;

Click the attachment button icon![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252F0nknSPkKQtpIMq5n0oPJ%252FAttachment%2520Button%2520Icon.png%3Falt%3Dmedia%26token%3De0ffc68e-12d7-43ae-9a24-71f2c0cfdef1\&width=30\&dpr=4\&quality=100\&sign=7ff89e18\&sv=2), click **Select a file from your device**, if you want to upload a new file.&#x20;

If you've already uploaded the file using File Manager, click on the **File Manager** tab, then select the file and click **Upload**.

<figure><img src="../../.gitbook/assets/attachment.gif" alt="" width="563"><figcaption></figcaption></figure>



Once the file is added to the chat, click the send button![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FHVWdk5Ki6PZL6fH1iV4t%252FSend%2520Button.png%3Falt%3Dmedia%26token%3D97b379a9-4dfe-4c5f-ab28-5ea724b5f02c\&width=35\&dpr=4\&quality=100\&sign=2c5f6f2f\&sv=2)



### Audio Message <a href="#audio-message" id="audio-message"></a>

To send an audio message using Seampify Chat, click the Record Voice button icon <img src="../../.gitbook/assets/image (304).png" alt="" data-size="line">, then from the menu that pops up, choose **Record Voice**.

<figure><img src="../../.gitbook/assets/record.gif" alt="" width="375"><figcaption></figcaption></figure>



Then click on the microphone button<img src="https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FgR6bt7sOZhz8NaabHJ0N%252FRecord%2520Voice%2520Message%2520Button.png%3Falt%3Dmedia%26token%3D9fbdbb5c-fe3b-499e-85dd-429b9951d668&#x26;width=30&#x26;dpr=4&#x26;quality=100&#x26;sign=1fd21485&#x26;sv=2" alt="" data-size="line">to record your voice. Once the voice is recorded, click the<img src="https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252Fu0WCeT7sGelRWxBEeALL%252FStop%2520Recording.png%3Falt%3Dmedia%26token%3D78287672-c876-48f9-808a-e13210906458&#x26;width=40&#x26;dpr=4&#x26;quality=100&#x26;sign=95736797&#x26;sv=2" alt="" data-size="line">stop button, and click **Upload** if the recording is okay. Or your may click the **Clear** button to re-record.

Once it's uploaded, click the send button![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FHVWdk5Ki6PZL6fH1iV4t%252FSend%2520Button.png%3Falt%3Dmedia%26token%3D97b379a9-4dfe-4c5f-ab28-5ea724b5f02c\&width=35\&dpr=4\&quality=100\&sign=2c5f6f2f\&sv=2)

## Private Notes

Here, you are also able to sent a private notes for internal communications. This will be visible to agents only. Type @ for internal tagging.

<figure><img src="../../.gitbook/assets/image (309).png" alt="" width="375"><figcaption></figcaption></figure>

Once send, the message will appear in Chat Area at that point of time when you send but it is only visible for internal.&#x20;

<figure><img src="../../.gitbook/assets/image (310).png" alt="" width="375"><figcaption></figcaption></figure>

The user who being tagged will received an notification on their Seampify app or desktop notification.

<figure><img src="../../.gitbook/assets/image (311).png" alt="" width="319"><figcaption></figcaption></figure>

# Marketing

## **Recent Campaigns**

This section displays the **top 5 most recent campaigns** that were created or run. Each row provides information such as:

* **Name**: The name of the campaign.
* **Channel**: The platform or channel used for the campaign.
* **Total Contacts**: The total number of contacts targeted in the campaign.
* **Message Template Name**: The template used for the campaign.
* **Schedule Time**: When the campaign was scheduled to start.
* **End Time**: When the campaign ended (if applicable).
* **Sent, Read, and Failed**: Metrics showing the number of messages sent, read, or failed.
* **Status**: The current state of the campaign (e.g., created, stopped, completed).

<figure><img src="../../.gitbook/assets/image (712).png" alt=""><figcaption></figcaption></figure>

To view about campaigns in detail, you can click the following link to go to the **Campaign Page**:\
[Go to Campaigns](../campaigns/)

## **Recent Drip Campaigns**

This section lists recent drip campaigns, which are automated, sequential messages sent over time. It includes details such as:

* **Campaign Name**: The name of the drip campaign.
* **List**: Indicates when each message in the sequence is sent.
* **Total**: The total number of messages was set in that List.
* **Sent and Failed**: Metrics on how many messages were sent or failed.
* **% Conversion**: The conversion rate of the campaign (currently 0% in this example).

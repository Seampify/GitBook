## Add a Step

Click on the Select Unit Field to define a the unit.&#x20;

<figure><img src="../../.gitbook/assets/image (409).png" alt="" width="563"><figcaption></figcaption></figure>

At Seampify, there are 5 units to run a step in a Drip Campaign. The units are,

* **Immediately** - Execute the step as soon as the contact(s) is assigned.
* **Minutes** - Execute the step after mentioned minutes defined in the After Field.
* **Hours** - Execute the step after mentioned hours defined in the After Field.
* **Days** - Execute the step after mentioned days defined in the After Field.
* Time and Date - Execute the exact time an date defined in the Select Date and Time Field.

Check _Remove From Campaign After Replied_, if you don't want the drip campaign to continue after a contact have responded.

Click **Add** once done.
{% endstep %}

## Add Message

After adding a step, you need to add a message(s) to it. And for that, click the **Add Message** button in the step.

<figure><img src="../../.gitbook/assets/image (410).png" alt=""><figcaption></figcaption></figure>

As you do that, the Add Message modal will popup. In that, you can select your Channel and Message Type.

<figure><img src="../../.gitbook/assets/image (411).png" alt=""><figcaption></figcaption></figure>

The available, message types are:

* Text Message - simple message without any button.
* Buttons/Options/Products Message - allows you to send text type, button type, list type or location type messages.
* Template Message - allows you to sent pre-appoved message templates or create a new template.

{% hint style="warning" %}
You can only use Text Message and Buttons/Options/Products Message in the Drip Campaign when it's within the 24-hour customer service window. Otherwise, choose Template Message.
{% endhint %}

Simply select a message type and continue with it.

### Template Message for Drip Campaign's Step

When you select the Template Message as the Message Type, you get the option to select a template you've created before or Create a new Template.

Select the template, then review its content and if everything's correct, click **Save**. Your added message will appear in the step as the following.

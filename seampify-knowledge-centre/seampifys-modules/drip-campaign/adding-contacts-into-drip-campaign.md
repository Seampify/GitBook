# Adding Contacts into Drip Campaign

You've created a Drip Campaign; however, to run it, you need to assign contacts to it. And to do that, there are 3 ways.

* [Using the Chat](adding-contacts-into-drip-campaign.md#assigning-contacts-to-a-drip-campaign-using-chat) - For single contact assign
* [Through Contacts](adding-contacts-into-drip-campaign.md#assigning-contacts-to-a-drip-campaign-using-contacts) - For bulk contacts assign
* [Through Automations ](../automations/create-a-new-automation/actions-steps.md#add-to-drip-campaign)- For single contact assignment automatically



## **Assigning Contacts to a Drip Campaign (Using Chat)**

{% stepper %}
{% step %}
### Select Contact

On your Chat screen, select the chat of the contact you want to assign to the Drip Campaign. You can use the chat search option to speed the process.&#x20;
{% endstep %}

{% step %}
### Add to Drip

Once opened the conversation, click the Options button in the top right corner. Then select **Add to Drip Campaign** from the available options.

<figure><img src="../../.gitbook/assets/image (231).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Assign Drip Campaign

A modal will appear, in that select the campaign to which you want to assign that particular contact.

<figure><img src="../../.gitbook/assets/image (232).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Click Add

Once selected, click **Add**. That's it; you've added a contact to the Drip Campaign. If the campaign's step is set to immediately, then it will be executed the moment you add the contact.
{% endstep %}
{% endstepper %}



## Assigning Contacts to a Drip Campaign (Using Contacts)

{% hint style="warning" %}
To do this, you will need to setup at least one [Drip Campaign ](create-a-drip-campaign.md)first.&#x20;
{% endhint %}

{% stepper %}
{% step %}
### Select Contacts

Select the contacts you want to add to the Drip Campaign.&#x20;

<img src="../../.gitbook/assets/image (334).png" alt="" data-size="original">
{% endstep %}

{% step %}
### Add to Drip Campaign

Click the Menu button ![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FIuURvhSfhvZU8ZTlpMYP%252FHorizontal%2520Menu%2520Options.png%3Falt%3Dmedia%26token%3Ddbc06bb8-de51-43aa-82ce-b6da06df3d6f\&width=300\&dpr=4\&quality=100\&sign=f13ab321\&sv=2) and then click **Add to Drip Campaign**.

<img src="../../.gitbook/assets/image (336).png" alt="" data-size="original">
{% endstep %}

{% step %}
### Select Campaign

Select the campaign to which you want to add the contacts, and then click **Save**.

<img src="../../.gitbook/assets/image (337).png" alt="" data-size="original">

That's it; you've added the contacts to a Drip Campaign. If the campaign's step is set to immediately, then it will be executed the moment you add the contact.
{% endstep %}
{% endstepper %}

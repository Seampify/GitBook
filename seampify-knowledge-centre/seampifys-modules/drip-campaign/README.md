# Drip Campaign

Drip campaign allow you to send a sequence of messages on a timely manner to a single or multiple contacts.

<figure><img src="../../.gitbook/assets/image (233).png" alt=""><figcaption></figcaption></figure>

The Drip Campaigns work around a Step-by-Step message broadcast system. Each step includes single or multiple messages of the same or different channels. To get the messages broadcasted of each step, the first step needs to be completed. And after that, the following steps will be executed based on the condition.

Using Drip Campaigns, you can send multiple messages to single or multiple contacts. The message type could be a simple message, List/Button/Options/Product Messages, or a [pre-approved message template ](../../useful-guides/conversation-through-whatsapp-cloud-api-1/understanding-whatsapp-message-template/)based on the selected channels.

{% hint style="warning" %}
WhatsApp Business Platform has a Customer Service Window (24-hour) in which businesses can send simple messages, List/Button/Options/Product Messages, or pre-approved templates. Outside the customer service window, the business can only send a message template.
{% endhint %}

## Pause a Drip Campaign

To pause a Drip Campaign, click the <img src="../../.gitbook/assets/image (432).png" alt="" data-size="line"> button under the Actions tab of the campaign. Once paused, the drip campaign will not run even there's [a new contact was added into the campaign.](adding-contacts-into-drip-campaign.md)

## Duplicate a Campaign

If you'd like to duplicate a campaign, click<img src="https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FMFKb5CR3QvlaV10MWhF8%252FDuplicate%2520Icon.png%3Falt%3Dmedia%26token%3D4dbc2f44-7395-4eb4-90a6-2f0014a7b5c0&#x26;width=40&#x26;dpr=4&#x26;quality=100&#x26;sign=1cb5318a&#x26;sv=2" alt="" data-size="line">Duplicate button.

<figure><img src="../../.gitbook/assets/image (429).png" alt=""><figcaption></figcaption></figure>

And as you do that, you'll be directed to the campaign builder with duplicate Steps and their messages. Now, [follow the steps to add more steps, messages](create-a-drip-campaign.md); edit or delete them. Then Save the campaign and assign contacts to finally run the Drip Campaign.

## Advanced Filters

Click <img src="../../.gitbook/assets/image (252).png" alt="" data-size="line"> button to access the filter options.&#x20;

<figure><img src="../../.gitbook/assets/image (253).png" alt="" width="563"><figcaption></figcaption></figure>

The filter options available are,

* **Field**
* **Operator**
* **Value**

{% stepper %}
{% step %}
First, you need to select the Field on the basis you want to filter the contacts. These Fields list is based on the Custom Fields you added into the system.

<img src="../../.gitbook/assets/image (254).png" alt="" data-size="original">

These are the default Fields for each account. If you wish to search from any different field, you will need to add a new Contact Fields and ensure Search Allowed? is allowed.&#x20;
{% endstep %}

{% step %}
After selecting the Field, select the Operator that will verify the Value in the column. There are a few operator types from which you can select one.

<img src="../../.gitbook/assets/image (255).png" alt="" data-size="original">

* IS - The Field and Value should exactly match to apply the filter.
* STARTSWITH - The value in the Field should start with the value in the Value field to run the filter.
* CONTAINS - If the value in the Field includes the value in the Value field, the filter will run.
* IS NOT - To apply the filter, the Field field should not match with the Value field.
* DOES NOT CONTAIN - To apply the filter, the Field field doesn't include the instances of the Value field.
* IN - The Contact(s) **In** the particular Tag(s).
* NOT IN - The Contact(s) **Not In** a particular Tag(s)
* MATCHES - The Contact ID Should Match the Value.
* BETWEEN - The Contact(s) Created or Updated **Between** the Date Range.
{% endstep %}

{% step %}
Once selected the operator, enter the value or select the option available in the Value field. The value field based on Field provides you with different options that are:

* Tag list for the Tag column.
* User / Group for the Contact Type column.
* Date Range (Today, Yesterday, Last 7 Days, Last 30 Days, and Custom) for Created At and Updated At column.
{% endstep %}

{% step %}
After adding the values in the fields, click **Submit**. And this will show the filtered contacts.
{% endstep %}
{% endstepper %}

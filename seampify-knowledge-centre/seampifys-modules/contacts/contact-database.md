{% stepper %}
{% step %}

{% endstep %}

{% step %}
Then click the![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FIuURvhSfhvZU8ZTlpMYP%252FHorizontal%2520Menu%2520Options.png%3Falt%3Dmedia%26token%3Ddbc06bb8-de51-43aa-82ce-b6da06df3d6f\&width=300\&dpr=4\&quality=100\&sign=f13ab321\&sv=2)More Options button, and then select **Bulk Update**.

* Add Tags
* Remove Tags
* Remarks

Select one from the above and make changes as required.
{% endstep %}
{% endstepper %}

If you wish to add a new or edit a Contact Field, refer [Contact Field.](filter-options/contact-fields.md#create-a-contact-field)

## Add to Drip Campaign

{% hint style="warning" %}
To do this, you will need to setup at least one [Drip Campaign ](../drip-campaign/create-a-drip-campaign.md)first.&#x20;
{% endhint %}

{% stepper %}
{% step %}
### Select Contacts

Select the contacts you want to add to the Drip Campaign.&#x20;

<img src="../../.gitbook/assets/image (334).png" alt="" data-size="original">
{% endstep %}

{% step %}
### Add to Drip Campaign

Click the Menu button ![](https://docs.rampwin.com/~gitbook/image?url=https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FhElFPtMZjXYjDDMBT5q2%252Fuploads%252FIuURvhSfhvZU8ZTlpMYP%252FHorizontal%2520Menu%2520Options.png%3Falt%3Dmedia%26token%3Ddbc06bb8-de51-43aa-82ce-b6da06df3d6f\&width=300\&dpr=4\&quality=100\&sign=f13ab321\&sv=2) and then click **Add to Drip Campaign**.

<img src="../../.gitbook/assets/image (336).png" alt="" data-size="original">
{% endstep %}

{% step %}
### Select Campaign

Select the campaign to which you want to add the contacts, and then click **Save**.

<img src="../../.gitbook/assets/image (337).png" alt="" data-size="original">

That's it; you've added the contacts to a Drip Campaign.
{% endstep %}
{% endstepper %}

Click the below to learn more about Drip Campaign.

[drip-campaign](../drip-campaign/)
{% endcontent-ref %}

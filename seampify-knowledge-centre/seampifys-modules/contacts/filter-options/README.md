# Filter Options

The Filter options let you quickly sort contacts.

<figure><img src="../../../.gitbook/assets/image (250).png" alt="" width="273"><figcaption></figcaption></figure>

By default, you see All Contacts; however, using the available options, you can filter contacts by:

* View contacts that are Pinned, using the **Starred contacts** optio&#x6E;**.**
* View Contacts that are Blocked, using the **Blacklisted** option.
* [**Contact Fields**](contact-fields.md) - Create different Field Types for contacts.&#x20;
* **Channels** - Filter contacts based on Channels.
* **Tags** - Filter contacts based on Tags.



## Bulk deletion for Tags

For tags that has already created, it will appears under Tags. Here, you can click on the tag to filter the contacts that has the tag.&#x20;



If you wish to delete the tags for all contacts, you can click on the X button.

<figure><img src="../../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure>

A confirmation message will pop out. Click **Confirm** to proceed.

<figure><img src="../../../.gitbook/assets/image (93).png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
Once a tag is being deleted, it will be removed completed. This step is not able to undo and restore.
{% endhint %}

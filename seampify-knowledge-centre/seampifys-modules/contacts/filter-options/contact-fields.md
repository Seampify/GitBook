# Contact Fields

## Overview

Contact Fields are used to save or obtain additional information about your customers using different Field Types. You can access that information using the Contacts module or while interacting with them using Chat.



## Accessing Contact Fields

There are 2 ways to access the Contact Fields:

1. Accessing Custom Fields from Contacts: go to Contacts → Contact Fields.

<figure><img src="../../../.gitbook/assets/image (354).png" alt="" width="321"><figcaption></figcaption></figure>

2. Accessing Custom Fields from Settings: go to Settings, then choose the Contact Fields tab.

<figure><img src="../../../.gitbook/assets/image (355).png" alt="" width="563"><figcaption></figcaption></figure>



## Create a Contact Field

{% stepper %}
{% step %}
### Click + Create Contact Field button

<img src="../../../.gitbook/assets/image (356).png" alt="" data-size="original">
{% endstep %}

{% step %}
### Fill up the informations

<img src="../../../.gitbook/assets/image (357).png" alt="" data-size="original">

* **Field Name** - Define the name of your Contact Field.
* **Field Type** - Select a Contact Field type from 8 different types that are,
  * Text(Single Line)
  * Text(Multi Line)
  * Email
  * Number
  * Date
  * Date Time
  * File
  * Object
* **Priority** - To assign importance level to regard the field as more important than other Contact Field. Numeric 1 is regarded as the top priority.
* **Search Allowed** - To allow search function within this Contact Field at Contact and Broadcast modules.
* **Show On Contacts Grid** - To showcase this Contact Field details in the [Contacts Database Columns ](contact-fields.md#adding-contact-fields-information)and [Chat Contact Info](contact-fields.md#access-contact-fields-using-chat) module.
* **Is Required** - When creating the contact, adding value(s) to this field is necessary.
{% endstep %}

{% step %}
### Click Save
{% endstep %}
{% endstepper %}

## Edit a Contact Field

You'll find created contact fields in the Contact Fields window, like the following.

<figure><img src="../../../.gitbook/assets/image (358).png" alt=""><figcaption></figcaption></figure>

To edit a contact field, click on the **Pen/Edit** Icon. Simply make the changes, and once edited, click **Update**.

<figure><img src="../../../.gitbook/assets/image (359).png" alt="" width="375"><figcaption></figcaption></figure>

{% hint style="warning" %}
Once a Contact Field has been created, you are unable to edit the Field Key and Field Type.
{% endhint %}



## Delete a Contact Field

You'll find created contact fields in the Contact Fields window, like the following.

<figure><img src="../../../.gitbook/assets/image (360).png" alt=""><figcaption></figcaption></figure>

To delete a contact field, click on the **Trash** Icon and further click **Confirm**.

<figure><img src="../../../.gitbook/assets/image (361).png" alt=""><figcaption></figcaption></figure>



## Adding Contact Field's Information

To add Contact Field's information for a particular contact, you can access the Contacts module and, from there, edit the contact. Then, scroll down to find the Contact Field(s).

<figure><img src="../../../.gitbook/assets/image (363).png" alt=""><figcaption></figcaption></figure>

Once added or edited the information, you can click **Save**.

{% hint style="info" %}
All the available contact fields with the 'Show on Contacts Grid' option enabled will display at the Contact Database columns.
{% endhint %}

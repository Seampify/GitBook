# Why Can’t I Upload My Contacts?

## 1. **Check File Format**

* **Supported Formats**: Ensure the file you’re uploading is in the csv format.
* **Action**: Convert your contact file to the supported format if necessary.
* **Tip**: Use the Seampify sample file template to ensure the correct structure.

***

## **2. Ensure Proper Data Formatting**

* **Correct Columns**: Verify that your file has the required column, Phone Number (mandatory) and name (recommended).
* **No invalid entries**: Ensure there are no invalid entries in your file.
* **Phone Number Format**: Check that phone numbers are in the correct format (e.g., 60123456789 or 123456789).
* **Action**: Edit the file to match the formatting requirements and re-upload it.

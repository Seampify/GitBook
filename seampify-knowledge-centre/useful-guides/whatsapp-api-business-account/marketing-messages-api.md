# Marketing Messages API

Meta has introduced a new and improved way to send WhatsApp marketing messages — the Marketing Messages API.



## Why This Matters

As of **April 2024**, Meta introduced **stricter frequency limits** on how often businesses can send marketing messages to a user. This was done to reduce spam and enhance the overall user experience on WhatsApp.

Due to these limits, some businesses may have experienced a **slight drop in message delivery rates**. This is because Meta’s systems limit the number of marketing messages a user can receive from all businesses combined.

To support businesses further, Meta has introduced an initiative that works **with these new limits** to enhance delivery and performance: the **Marketing Messages API**.



## What is Marketing Messages API?

The Marketing Messages API is a feature of WhatsApp Business Platform designed to optimize the delivery of marketing messages.

It allows for more dynamic messaging limits, so marketing messages with high engagement (e.g. messages that receive more reads) can reach more customers. It is designed to provide a better experience for customers and potentially better business results compared to the Cloud API for marketing messages.

{% hint style="success" %}
In India, MM Lite API marketing messages that receive higher engagement (e.g., reads) observed up to **9% higher messages delivered** compared to Cloud API
{% endhint %}



## Key Benefits of Marketing Messages API

* **Improved Reach**\
  Marketing Messages API can improve your marketing message reach by **up to 9%** compared to cloud API.
* **Higher Engagement**\
  By prioritizing users based on likelihood to engage, your messages see better **delivery and read rates**.
* **Meta-Compliant Delivery**\
  Marketing Messages API ensures that messages are sent within the boundaries of Meta’s **new frequency restrictions**.
* **No Additional Cost**\
  Switching to Marketing Messages API doesn’t cost extra — it uses the same message credits.
* **Non-Disruptive**\
  Your current message templates, campaigns, and automation flows are unaffected.\
  Marketing Messages API only applies to **marketing messages** (not service, utility, or OTP messages).



## Things to Know Before You Start

* **Marketing-only**: Marketing Messages API is specifically for **marketing messages**.
* **Terms & Conditions**: You’ll need to accept Meta’s updated Marketing Messages API Terms & Conditions to activate it. Refer below on the step to configure Marketing Messages API

## Monitor metrics and recommendations

Once Marketing Messages API enabled, you’ll have access to benchmark metrics directly in Meta’s WhatsApp Manager. These metrics serve as a reference to compare the performance of your marketing messages with the average results from other companies.

Here's how to access them:

1. In **Business Manager**, go to **WhatsApp Manager.**
2. Click **Manage templates.**
3. Choose the **marketing template** you want to analyze.
4. In the dropdown menu highlighted in red, select the option **Marketing Messages Lite API.**
5. The **benchmark metrics** and **recommendation cards** will appear below the template preview, in the panel on the left.

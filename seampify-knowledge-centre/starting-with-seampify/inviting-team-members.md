# Inviting Team Members

**Team Settings** allows you to create user accounts for your employees, granting either full control or limited access based on their roles.&#x20;

{% hint style="warning" %}
To add a team member, you must first [create a roles](../seampifys-modules/settings/business-settings/roles-and-permissions.md#create-a-role).
{% endhint %}



## Add Member

1. Navigate to **Settings > Teams**
2. Click the " **+ Add Member** " button

<figure><img src="../.gitbook/assets/image (579).png" alt=""><figcaption></figcaption></figure>

3. Create Team Member&#x20;

<figure><img src="../.gitbook/assets/image (580).png" alt=""><figcaption></figcaption></figure>

This will open the create user modal with the following fields,

* Full Name
* Email
* Password
* Departments
* Roles
* Max Chat Assignment
* Allow User to SSO login only - Login via Gmail or Microsoft.

Simply add the information, and once you've added all click **Save**. As soon as you save the Team member it will appear on the page like the below list.

<figure><img src="../.gitbook/assets/image (549).png" alt=""><figcaption></figcaption></figure>

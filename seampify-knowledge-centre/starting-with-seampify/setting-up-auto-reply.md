# Setting up Auto Reply

## **Import the Pre-built Automation Template**

1. **Go to** `Automations` in your dashboard.
2. **Click on** `Import Automation Template`.

<figure><img src="../.gitbook/assets/image (743).png" alt=""><figcaption></figcaption></figure>

3. **Click "**`General`**" tab.**&#x20;
4. **Search for the template** named `Broadcast Respond Auto Reply & Assignment`.
5. Click the `"Preview"` button of the template&#x20;

<figure><img src="../.gitbook/assets/image (744).png" alt=""><figcaption></figcaption></figure>

6. Import the template into your account.

<figure><img src="../.gitbook/assets/image (748).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
_Tip: You can explore other automation templates to find ones that match your use case._
{% endhint %}



## Configure the Button's Trigger

1. Double-click on the Trigger action box.
2. Select List/Button Callback ID matches.
3. Enter the keyword for the button you wish to trigger the automation (e.g., RSVP Now).
4. Click Update Node once you've entered the keyword.

<figure><img src="../.gitbook/assets/Seampify-GoogleChrome-26December20241-ezgif.com-video-to-gif-converter (2).gif" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
_Note: Ensure the `keyword` matches the `Button ID` exactly when you sent the messages with button, to trigger the correct automation._
{% endhint %}

<figure><img src="../.gitbook/assets/image (745).png" alt=""><figcaption></figcaption></figure>



## Customise Actions for the Trigger

1. Double-click on the action box (Auto Reply Buttons/Options/Products).
2. In the settings panel on the right, enter your desired reply message or action details.
3. Click Update Node to save changes.

<figure><img src="../.gitbook/assets/image (747).png" alt=""><figcaption></figcaption></figure>



## Add Multiple Triggers for Multiple Buttons

1. To add more buttons, add multiple Triggers in the same flow.
2. Assign a unique keyword to each button (e.g., RSVP Now, Learn More).
3. Ensure each keyword is distinct to avoid triggering multiple automations.
